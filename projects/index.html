AI 모의면접 에이전트

부산 청년 취업 맞춤형 멘토링 Agent 중 모의면접 파트

문제 정의

부산 지역 청년은 지역 채용 정보를 찾기 어렵고, 1:1 취업 멘토링이나 실전 면접 연습을 받을 기회도 부족합니다. 연습을 해도 내 답변이 괜찮은지, 말은 어땠는지, 시선 처리는 어땠는지 알려 줄 사람이 없습니다.

역할

팀(5인)에서 모의면접 AI 로직을 맡았습니다. 면접 진행 규칙, AWS AI 서비스 호출, 측정과 점수 계산, 리포트 생성까지 ai/interview/ 모듈을 설계하고 구현했습니다. 백엔드(API · DB · 배포)와 프론트(화면 · 녹음 · 카메라)는 팀원이 맡았고, 그 사이의 함수 입출력 계약은 제가 설계해 넘겼습니다.

구현
  • 공고 맞춤 질문 생성: 채용공고 본문과 자기소개서를 읽고 기본 질문 3개를 만듭니다. 공고마다 항목 이름이 달라도 AI가 업무 · 요건 · 인재상을 찾아 씁니다.
  • 툴을 쓰는 꼬리질문 에이전트: Strands Agents로 만든 에이전트가 ‘자소서 검색 · 이전 답변 조회 · 남은 질문 조회’ 툴 3개를 직접 써 보고 꼬리질문이 필요한지 판단합니다. 판단에 실패해도 면접이 끊기지 않게 설계했습니다.
  • 음성 면접: Polly로 질문을 음성으로 들려주고, Transcribe로 답변을 글로 바꾼 뒤 단어별 시간으로 발화 속도와 긴 침묵을 측정합니다.
  • 카메라 태도 분석: Rekognition으로 얼굴 방향과 시선을 읽고, 처음 몇 장으로 개인 기준값을 잡은 뒤 그 기준에서 얼마나 벗어나는지로 태도를 측정합니다.
  • 3축 채점 리포트: 내용 50 · 전달력 25 · 태도 25 비율로 합산하고, 카메라나 음성을 쓰지 않은 경우에도 비율을 다시 나눠 점수를 냅니다.

식재료 사진 기반 영양 분석 · 레시피 추천 웹 서비스

문제 정의

1인 가구는 식재료를 잊어 버리거나 배달 음식에 의존하기 쉽습니다. 기존 서비스는 재료를 직접 입력해야 하고, 영양 분석과 레시피 추천이 서로 다른 서비스에 나뉘어 있었습니다.

역할

팀장(4인)으로 일정과 통합을 이끌고, 식재료 이미지 인식 모델과 백엔드를 맡았습니다.

  • AI Hub 한국 식재료 이미지로 EfficientNetB0를 전이학습해 20종을 분류했습니다.
  • 무료 서버(RAM 512MB)에서 모델이 메모리를 넘겨 서버가 재시작되는 문제를 TFLite float16 변환으로 해결했습니다.
  • FastAPI 서버 설정과 재료 인식 API를 만들었습니다.
기술
TensorFlow / Keras EfficientNetB0 TFLite FastAPI Gemini FAISS (RAG) Docker
